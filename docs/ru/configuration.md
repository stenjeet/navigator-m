# Конфигурация

[English](../en/configuration.md) | **Русский**

Этот справочник перечисляет все YAML-параметры, которые используют runtime-узлы,
вместе со значениями по умолчанию, единицами измерения и кратким пояснением.
Если не указано иное, параметры задаются в единицах СИ.

## Как загружаются параметры

Каждый YAML-файл содержит по одной секции верхнего уровня на узел. Имя секции
должно совпадать с именем узла, которое задаёт launch-файл. В
`occupancy.yaml` используется шаблон `/**`, потому что launch-файл запускает
один и тот же маппер дважды под разными именами (`occupancy_grid_ekf` и
`occupancy_grid_gt`).

| Файл | Секция узла | Загружается из |
|---|---|---|
| `navigator_sim/config/motion.yaml` | `motion_node` | `simulation.launch.py` |
| `navigator_sim/config/sensors.yaml` | `uwb_model_node`, `lidar_model_node` | `simulation.launch.py` |
| `navigator_localization/config/ekf.yaml` | `ekf_node` | `simulation.launch.py`, `mapping.launch.py` |
| `navigator_slam/config/occupancy.yaml` | `/**` (все экземпляры маппера) | `mapping.launch.py` |
| `navigator_slam/config/landmarks.yaml` | `landmark_node` | `landmarks.launch.py`, `slam.launch.py` |
| `navigator_slam/config/ekf_slam.yaml` | `ekf_slam_node` | `slam.launch.py` |

`simulation.launch.py` и `mapping.launch.py` принимают альтернативные файлы
датчиков и EKF через `sensors_params:=...` и `ekf_params:=...`. Именно так
инструмент сценарного анализа запускает альтернативные профили шума.

Синтаксис переопределения параметров ROS тоже работает:

```bash
ros2 run navigator_localization ekf_node --ros-args -p uwb_sigma:=0.10
```

## motion.yaml

| Параметр | По умолчанию | Единица | Назначение |
|---|---:|---|---|
| `start_x` | `1.5` | m | Начальная координата `x` траектории. |
| `start_y` | `1.5` | m | Начальная координата `y` траектории. |
| `start_yaw` | `0.0` | rad | Начальный курс. |
| `side_length` | `4.0` | m | Сторона квадратной траектории. |
| `linear_velocity` | `0.35` | m/s | Скорость движения вперёд на прямых участках. |
| `angular_velocity` | `0.60` | rad/s | Угловая скорость на поворотах. |
| `time_step` | `0.05` | s | Шаг интегрирования и публикации. |
| `wheel_radius` | `0.09` | m | Радиус колеса для `joint_states`. |
| `wheel_base` | `0.42` | m | Колея (расстояние между колёсами). |
| `loops` | `1` | — | Число квадратных кругов. Задайте `2`, чтобы проверить замыкание петли. |

## sensors.yaml

Файл содержит две секции узлов. По умолчанию оба датчика используют один и тот
же seed.

### uwb_model_node

| Параметр | По умолчанию | Единица | Назначение |
|---|---:|---|---|
| `random_seed` | `12025` | — | Seed для воспроизводимого шума и пропусков. |
| `uwb_sigma` | `0.05` | m | СКО аддитивного шума дальности. |
| `uwb_dropout_probability` | `0.03` | — | Вероятность того, что дальность равна `NaN`. |
| `uwb_biases` | `[0.02, -0.03, 0.04, 0.01]` | m | Смещение по каждому якорю для A1..A4. |
| `uwb_rate_hz` | `10.0` | Hz | Частота публикации. |
| `anchors` | не задан | m | Необязательный плоский список `x, y, z`. Если не задан, используются `world.UWB_ANCHORS`. |
| `outage_start_s` | `0.0` | s | Начало окна полного отказа СШП. |
| `outage_end_s` | `0.0` | s | Конец окна отказа; `0.0/0.0` отключает его. |

Не задавайте `anchors: []`. ROS не может вывести тип пустой последовательности
YAML и объявляет параметр неинициализированным. Чтобы использовать раскладку
якорей полигона по умолчанию, не указывайте ключ. При изменении раскладки
задайте те же якоря в `ekf.yaml` (и `ekf_slam.yaml`, если используется SLAM).

### lidar_model_node

| Параметр | По умолчанию | Единица | Назначение |
|---|---:|---|---|
| `random_seed` | `12025` | — | Seed для воспроизводимого шума и пропусков. |
| `lidar_sigma` | `0.02` | m | СКО шума дальности. |
| `lidar_bias` | `0.01` | m | Постоянное смещение дальности. |
| `lidar_dropout_probability` | `0.01` | — | Вероятность отсутствия отражения (`inf`). |
| `lidar_range_min` | `0.12` | m | Минимальная принимаемая дальность. |
| `lidar_range_max` | `8.0` | m | Максимальная принимаемая дальность. |
| `lidar_beams` | `360` | — | Число лучей на скан. |
| `lidar_rate_hz` | `10.0` | Hz | Частота публикации. |

Смещение лидара не является параметром модели датчика: оно задаётся в
`world.LIDAR_OFFSET` и используется при трассировке лучей, построении сетки
занятости и выделении ориентиров.

## ekf.yaml

| Параметр | По умолчанию | Единица | Назначение |
|---|---:|---|---|

| `initial_yaw` | `0.0` | rad | Начальная оценка курса. |

| `initial_std_y` | `0.10` | m | Начальное СКО (1σ) по `y`. |

| `anchor_names` | `['A1', 'A2', 'A3', 'A4']` | — | Имена, используемые в логах. |
| `anchors` | тройки A1..A4 | m | Положения якорей в виде плоских `x, y, z`. |
| `predict_rate_hz` | `20.0` | Hz | Частота прогноза. |
| `path_max_poses` | `5000` | — | Максимальное число поз в `/estimate/path`. |
| `path_every_n` | `4` | — | Добавлять в путь каждое N-е предсказание. |

постоянны во времени; при изменении частоты таймера их нужно масштабировать.

## Конфигурация RViz

`navigator_description/config/navigator.rviz` не является файлом параметров ROS.
Он задаёт фиксированную систему координат (Fixed Frame, `map`) и начальный набор
отображений: модель робота, TF, истинные траекторию и позу, позу и траекторию
EKF, маркеры полигона, лидарные сканы, сетки занятости, маркеры ориентиров и
маркеры SLAM.
